# Repaso WEB — Operación TI (ISO + Planes + ITIL v3)

Página web interactiva (solo `index.html` + `style.css`) para repasar:

- **Normas ISO**: ISO/IEC 20000 (servicios), ISO/IEC 27001 (SGSI), ISO 22301 (continuidad).
- **Planes**: contingencia, continuidad (BCP), recuperación ante desastres (DRP), plan operativo.
- **ITIL v3**: ciclo de vida del servicio, procesos clave, métricas (KPIs / SLAs).

## Cómo abrirla

1. Abre el archivo `index.html` en tu navegador (doble clic).
2. Navega con el **menú** superior (incluye submenús).

## Interactividad incluida

- **Menús con submenús** (ISO / Planes / ITIL v3).
- **Buscador**: filtra secciones por palabras clave.
- **Tabs ISO**: cambia entre ISO 20000 / 27001 / 22301.
- **Checklist** de plan de contingencia: se guarda en el navegador (localStorage).
- **Botón “Copiar”** en comandos.
- **Mini‑quiz**: 3 preguntas y calificación.

## Archivos del proyecto

- `index.html`: estructura + interactividad (JavaScript embebido).
- `style.css`: estilos (tema oscuro moderno + componentes).
- `README.md`: este archivo.

## Notas

El contenido es **resumen educativo**. Para un entorno real, ajusta a las políticas, riesgos, y requerimientos de tu organización.
