# Página web — Mantenimiento y operación de sistemas informáticos

Proyecto sencillo con una sola página informativa en español.

## Archivos

| Archivo      | Descripción                                      |
|-------------|---------------------------------------------------|
| `index.html`| Contenido HTML de la página                       |
| `style.css` | Estilos (colores, tipografía, layout)             |
| `readmi.md` | Este archivo de ayuda                             |


## Contenido

La página resume de forma general:

- Qué es operar y mantener un sistema informático
- Tipos de mantenimiento: preventivo, correctivo y evolutivo
- Buenas prácticas de operación
- Notas básicas de seguridad

Es material educativo de ejemplo; adapta el texto a las normas de tu centro u organización si lo usas con fines reales.
